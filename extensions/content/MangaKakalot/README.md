# MangaKakalot

Independent native Manko API 2.0 provider for https://www.mangakakalot.gg. The shared implementation is in `packages/mangabox`.

Public behavior/layout references: https://github.com/Aidoku-Community/sources/tree/main/templates/mangabox and https://github.com/Aidoku-Community/sources/tree/main/sources/en.mangakakalot. No Yomu package or implementation is included. Original code is Apache-2.0.

MangaBox denotes this family of sites, rather than a fourth standalone provider. Local packages are unpublished. Chapter API responses and HTML variants are exercised by synthetic fixtures in the behavior suite.
